# Catálogo Express: cómo adaptarlo a un cliente

Archivo base: `demo-catalogo.html`.

1. Edita el bloque NEGOCIO (nombre, eslogan, WhatsApp, ciudad, horario, delivery).
2. Cambia colorPrincipal por el color del cliente (un solo valor hexadecimal).
3. Reemplaza la lista PRODUCTOS (nombre, categoria, precioUsd, detalle, emoji).
4. Pon modoDemo en false: desaparece la barra de demostración y los pedidos van al WhatsApp del negocio.
5. Borra el bloque "Medición F&V" del <head> (los scripts de Google Analytics y Clarity).
6. Cambia <title>, la descripción y quita la línea robots "noindex" si el cliente quiere salir en Google.
7. Publica este único archivo.
